BLUEPRINT ARCHITECTURE

React/Vite client
  -> Express API
     -> PostgreSQL (pg)
     -> EvaluationService
        -> CommonMistakeCheck (deterministic)
        -> Evaluator contract
           -> GeminiEvaluator (current)
           -> RuleBasedEvaluator (future)
           -> HumanEvaluator (future)

Submission evidence = explanation text + React Flow nodes/edges.
Evaluation output = summary + 8 qualitative criteria.
Criterion = rating + evidence + concern + suggestion + confidence.

Lifecycle:
Draft -> Submitted -> Evaluating -> Completed
                         \-> Failed
